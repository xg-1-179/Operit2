## 5. 时空可组合性改造（核心代码，已编译进 APK）

设计目标：时间 = 卸载时完整撤销副作用；空间 = 依赖出现/消失时响应式激活/停用；默认不影响存量插件。

### 时间可组合性
- `ToolPkgRegistrationBridge.rs`：新增 `ToolPkg.onUnload(fn)`、`ToolPkg.effect(fn)`（执行并登记返回的 disposer），以及全局 `__operitLifecycleDispatch(event)`；逆注册顺序、逐个 `await`、异常隔离、清空处理器数组。
- `javascript.rs`：`JsExecutionEngine` 新默认方法 `dispatch_lifecycle(&self, event)`（默认空实现，不破坏测试假引擎）。
- `JsEngine.rs`：`JsEngineWorker::dispatch_lifecycle` + `JsEngineState::dispatch_lifecycle_on_current_thread`，通过 `executeHostJavaScriptRuntimeStateTask` 在引擎线程同步执行，5 秒超时（`TOOLPKG_LIFECYCLE_TIMEOUT_SECONDS`）；实例方法走异步桥接，失败只记日志。
- `ToolPkgManager.rs`：`removeExecutionEnginesMatching` 在 `engine.destroy()` 前调用 `dispatch_lifecycle("unload")`，覆盖禁用、删除、重载替换、工厂更新全部销毁路径。
- `AIToolHandler.rs`：`AIToolHandlerState` 新增 `toolPkgToolOwners`、`toolPkgPruneListenerRegistered`；`registerPackageTools` 记录 ToolPkg 归属；`getOrCreatePackageManager` 注册 runtime 变更监听器；`pruneInactiveToolPkgTools` 按"当前活跃容器 ∪ 子包"集合摘除 `pkg:tool`（不再依赖调用期拦截）。

### 空间可组合性
- `RuntimePackageManager.rs`：
  - 新增 `containerStrictDependencies`（读取清单扩展字段 `strict_dependencies`）、`containerDependenciesSatisfied`（已安装 + 已启用/子包启用 + min/max 版本）、`isPackageRuntimeActive`。
  - `getEnabledToolPkgContainerRuntimes` 过滤未满足依赖的 strict 容器 → 所有桥（UI 槽位/hook/provider）响应式收缩/恢复。
  - `getEffectivePackageTools` 对未激活的 strict 包返回 `None` → 工具目录/提示词实时收缩。
- 语义：`strict_dependencies` 未声明的插件保持原有行为（只展示依赖问题，不强制停用），实现双兼容。

## 6. dsh 兼容层（tools/dsh-compat/）

- `cordis-core.mjs`：Context 服务容器（服务以 `ctx.<name>` 暴露）、`inject` 依赖 → Fiber PENDING/ACTIVE、服务消失 → 依赖方 dispose、`effect()` 可逆、事件 `emit/parallel/serial/bail/waterfall`、`isolate()` 子上下文、`Service` 基类、`createApp`。
- `dsh-shim.mjs`：dsh 服务 → Operit2：`tools`（`ctx.tools.register` 运行时注册）、`fs`（Tools.Files 异步）、`http`（Tools.Net）、`config`（插件配置目录 JSON）、`logger`、`storage`（Tools.Storage.request）；`bootDshPlugin` 幂等挂载并登记 `ToolPkg.onUnload` 做整树 dispose；`invokeRuntimeTool` 供生成的工具包装器调用。
- `port-dsh-plugin.mjs`：esbuild 打包插件 + 内嵌兼容层 → Node 内 mock 捕获工具清单 → 生成 `manifest.json`（`strict_dependencies: true`）、`main.js`、`dist/tools.js`（METADATA + bundle + 包装器）→ 可选 fflate 打 `.toolpkg`。
- 测试：`tests/cordis-core.test.mjs`（8 项）、`tests/dsh-shim.test.mjs`（3 项），全部通过 `node --test`。
- 兼容范围：可移植 = 在 apply 注册工具、使用 fs/http/config/logger/storage、纯 JS 依赖；不可移植 = Node 原生模块、dsh 专有服务（llm/sessions/agentLoop/sandbox/approval/mcp）、同步 fs、纯 UI 美化插件。
